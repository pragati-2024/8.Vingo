---

## Setup Instructions

1. Install dependencies:

```
npm install
```

2. Run development server:

```
npm run dev
```

---

## Key Folders

* **components/** → reusable UI components
* **pages/** → application screens
* **redux/** → state management
* **hooks/** → custom hooks
* **assets/** → images, icons, etc.
