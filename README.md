<h1>🚀 Vingo - Food Delivery App</h1>

<p>A full-stack food delivery application built with MERN stack.</p>

<hr/>

<h2>🌐 Live Links</h2>

<ul>
  <li><b>Frontend (Vercel):</b> <a href="https://8-vingo-m793.vercel.app/">https://8-vingo-m793.vercel.app/</a></li>
  <li><b>Backend (Render):</b> <a href="https://eight-vingo-urwo.onrender.com/">https://eight-vingo-urwo.onrender.com/</a></li>
</ul>

<hr/>

<h2>🧠 Tech Stack</h2>

<ul>
  <li>Frontend: React + Vite</li>
  <li>Backend: Node.js + Express</li>
  <li>Database: MongoDB Atlas</li>
  <li>Realtime: Socket.io</li>
  <li>Auth: JWT + Cookies</li>
</ul>

<hr/>

<h2>⚙️ Backend Setup</h2>

<pre>
cd backend
npm install
</pre>

<h3>🔐 Environment Variables</h3>

<pre>
PORT=8001
MONGO_URI=your_mongodb_atlas_uri
JWT_SECRET=your_secret_key
CLIENT_URL=https://8-vingo-m793.vercel.app
PEXELS_API_KEY=your_pexels_api_key
</pre>

<h3>▶️ Run Backend (Local)</h3>

<pre>
npm run dev
</pre>

<p>Backend runs on: <b>http://localhost:8001</b></p>

<hr/>

<h2>🖼️ Auto Image Feature</h2>

<ul>
  <li>If no image is provided, backend fetches image from Pexels API</li>
  <li>Requires PEXELS_API_KEY in .env</li>
</ul>

<pre>
npm run fix:auto-images
</pre>
